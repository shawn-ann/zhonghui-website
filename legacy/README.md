# 旧版静态原型（存档）

这里保存的是 CMS 上线前的静态 HTML 原型，仅用于查阅历史设计和内容，不参与正式站构建，也不再作为线上页面维护。

- 正式站点由 `cms/` 生成，输出到 `cms/releases/`。
- 原型中的图片引用已改为指向仓库根目录的 `../img/`。
- 预览时请从仓库根目录启动静态服务，再访问 `/legacy/index.html`：

```bash
python3 -m http.server 8321 --bind 127.0.0.1
# http://127.0.0.1:8321/legacy/index.html
```

不要在这里继续开发新功能；新页面请使用 CMS 配置。
