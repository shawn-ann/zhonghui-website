## 1. 背景与目标

### 1.1 背景
P1/P2 已实现 Payload 表单式的区块编辑 + 静态生成。运营反馈：
- 表单式编辑**不直观**；看不到真实效果；
- 需要"**可视化画布**"：左侧组件以效果缩略图呈现、拖入画布、所见即所得、右侧改属性。

### 1.2 目标
用**可视化画布编辑器完全取代** Pages 的默认表单式区块编辑，打通**编辑 → 预览 → 发布**主流程：
- 组件库（效果缩略图）拖入画布；
- 画布所见即真实渲染结果（单一渲染源）；
- 内联改字、拖动排序、属性面板；
- 保存草稿、发布（触发静态生成）。

### 1.3 范围（本阶段）
- 动态预览路由（草稿数据 → 完整 HTML）。
- 画布编辑器（覆盖 Pages Edit 视图）：组件库 + 顶层拖动 + 内联改字 + 属性面板 + 媒体选择 + 保存草稿 + 发布。
- Pages 启用原生 Drafts。

### 1.4 范围外（后续）
- **画布内嵌套拖拽**（往 grid 格内直接拖子组件/跨格）→ **二阶段**（本阶段格与子组件在属性面板管理）。
- 汉化 pass、集合（案例/资讯）、站点配置（菜单/主题）→ 父设规划，延后。
- 安全部署（Nginx/HTTPS/限流）→ 延后。

## 2. 已定决策

| 议题 | 结论 |
|---|---|
| 画布渲染 | **同构复用**现有纯渲染模块（`render/blocks`、`shell`、`nav`、`footer`）在浏览器运行 |
| 画布形态 | **iframe（`srcdoc`，同源）+ 父级叠加编辑器**（无需 postMessage） |
| 刷新方式 | 编辑时**客户端即时重渲** `srcdoc`，无网络往返 |
| 草稿模型 | Pages 启用 **Payload 原生 Drafts**（`versions.drafts`，`_status` + 版本） |
| 与表单关系 | 画布**完全取代** Pages 默认表单编辑 |
| 属性面板 | **C 方案**：通用字段控件 + 每区块一份字段清单 |
| 嵌套 | **MVP**：顶层画布拖拽；grid 的格/子组件在**属性面板**管理 |
| 发布 | 置 `_status=published` + 触发静态生成 |

## 3. 架构

### 3.1 数据模型
- **不变**（P2 的 `Pages.blocks` 嵌套 blocks）。
- `Pages` 启用 Drafts：
  ```ts
  versions: { drafts: true }
  ```
  以 `_status`（`draft` / `published`）区分；生成器 `loadSiteData` 改为只取已发布（`_status: 'published'`）。

### 3.2 同构渲染
- 现有纯渲染模块（`src/render/blocks/*`、`shell`、`primitives`、`nav`、`footer`、`styles/base.css`）**无 Node 依赖**，可在浏览器直接复用。
- 新增一个"整页 HTML 组装"函数（当前在 `layout.ts` 的 `renderPage` 基础上，抽出可在客户端调用的入口），供画布与预览共用。
- 保证"**画布所见 = 生成结果**"（同一份渲染源码）。

### 3.3 画布 iframe 模型
- 画布为一个 `<iframe>`，其 `srcdoc` = 由当前编辑中的区块数据 + 固定 nav/footer + 样式组装出的完整 HTML。
- `srcdoc` 为**同源**，父级 React 可直接 `iframe.contentDocument` 访问，挂载：
  - 选中框 + 拖动手柄（顶层区块）；
  - 双击进入 `contenteditable` 内联改字（绑定到区块字段）；
  - 点击选中 → 右侧属性面板联动。
- 改动 → 重建 `srcdoc`（或按需增量更新），即时反映。

### 3.4 动态预览路由
- 新增 Next 路由（如 `/preview/pages/:id`，受保护 + 可选 token），用**草稿数据** + 同渲染模块输出完整 HTML。
- 用途：发布前查看"完整页"、分享/独立预览（画布外的正式预览）。

### 3.5 编辑器入口
- **覆盖 Pages 的 admin Edit 视图**（Payload `admin.components.views` 自定义 React 视图），默认表单不再作为主入口。

### 3.6 属性面板
- **通用控件**：文本、多行文本、数字、下拉、开关、图片/媒体选择、链接、背景（图/色/渐变）。
- **每区块一份字段清单**：描述该区块有哪些字段、用哪个控件、中文 label。新增区块 = 加一份清单（不必从零写控件）。

### 3.7 保存 / 发布
- **保存草稿**：编辑防抖写回 Payload draft（`_status=draft`）。
- **发布**：置 `_status=published` + 触发静态生成（本阶段先复用 `npm run generate`；发布按钮/端点属主流程 C）。
- **预览**：画布即实时预览；另有 `/preview/...` 完整预览。

### 3.8 安全边界
- 编辑器、`/preview` 均在**受保护后台内**（登录态；预览可加 token）。公开站点仍纯静态。

## 4. 编辑体验（画布 UI）

见 UI 稿 `editor-ui.html`，要点：
- **顶栏**：页面标题 · 状态（草稿/已发布 · 未保存）· `预览 / 保存 / 发布`。
- **左栏 · 组件库**：每个区块一个**效果缩略图**卡片；拖动到画布添加。
- **中栏 · 画布**：iframe 真实渲染；选中区块显示红框 + `⠿拖动` + `双击改字`；块之间可拖动排序；支持删除。
- **右栏 · 属性面板**：随选中区块切换；用通用控件；底部对 `grid` 提供"格与子组件"管理（MVP）。
- 媒体选择：弹窗上传/从媒体库选择。

---

## 5. 组件级细节

- **组件库内容**：`pageBlocks`（`banner / text / image / imageText / button / richText / gallery / slider / grid`），各配缩略图。
- **顶层操作**：添加、拖动排序、删除、选中。
- **内联改字**：`text`/`imageText`/`button` 等的文本字段可双击编辑；提交后写回区块数据并重渲。
- **属性面板字段清单（示例）**：
  - `banner`：标题、副标题、变体（左右/整图）、配图、装饰图、背景、浅粉底。
  - `text`：标题、正文、对齐、背景、浅粉底。
  - `image`：图片、替代文本、链接、背景、浅粉底。
  - `imageText`：图片、标题、描述、链接、背景、浅粉底。
  - `button`：文字、链接、样式（实心/描边）、背景、浅粉底。
  - `richtext`：富文本编辑、背景、浅粉底。
  - `gallery`：图片列表、列数、背景、浅粉底。
  - `slider`：图片列表、背景。
  - `grid`：列数、间距、格与子组件列表（MVP）。背景、浅粉底。

## 6. 测试策略

- **同构渲染入口**：纯函数单测（给定区块数据 → 完整 HTML 含 nav/footer）。
- **预览路由**：路由单测（草稿数据渲染、未登录拒绝）。
- **编辑器**：组件测试（用 React Testing Library / Vitest）：
  - 组件库渲染出各区块缩略图；
  - 拖入 → 区块数据新增；
  - 选中 → 属性面板显示对应字段；
  - 改字段 → 画布 HTML 更新；
  - 保存草稿 / 发布调用对应接口。
- **集成**：草稿 → 预览 → 发布 → 生成，端到端（Playwright）。
- 沿用 P1/P2 的 `npm test` + `npx tsc --noEmit` 门槛。

---

## 7. 验收

1. 在 Pages 编辑页看到**画布编辑器**（左组件库 / 中画布 / 右属性）。
2. 从组件库拖入一个区块到画布 → 画布即时出现该区块（真实渲染）。
3. 双击标题内联改字 → 画布即时更新。
4. 拖动排序 → 顺序更新；选中 → 属性面板正确。
5. 保存草稿后刷新页面，编辑内容保留（草稿）。
6. 点发布 → `_status=published` 且 `npm run generate` 产出含该页的静态 HTML。
7. `/preview/pages/:id` 能用草稿渲染完整页。

## 8. 已知取舍

- **画布内嵌套拖拽**本阶段不做（grid 的格/子组件在属性面板管理）。
- 编辑器仅覆盖 **Pages**；集合/设置等仍用 Payload 默认后台（汉化延后）。
- 主题令牌仍静态（站点配置延后）。
- 发布暂以 `npm run generate` 触发（发布按钮/端点属主流程 C，随后接）。
