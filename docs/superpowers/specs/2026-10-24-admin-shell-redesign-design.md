# 管理后台外壳与视觉重构设计

日期：2026-10-24
状态：已确认，待实现
范围：Payload 管理后台外壳、导航、面包屑、通用组件，以及页面列表、菜单、站点设置、页面编辑器顶栏

## 1. 背景与问题

当前后台直接使用 Payload 默认结构，每个页面同时出现：

1. 全局顶栏：汉堡菜单、品牌图标、账号头像；
2. 文档头：页面名称、`编辑 / 版本 / API` 页签；
3. 自定义视图自己的标题与说明。

结果横向栏目占用两层，入口分散，页面留白和控件样式也不统一。管理后台只需要服务少量内容编辑者，不需要向普通用户暴露 API 或版本入口。

## 2. 目标

- 用一套固定的左侧导航取代默认顶部全局栏和文档页签，消除“两层栏目”。
- 建立统一的页面头部：面包屑、标题、说明、操作按钮。
- 统一后台视觉语言：暖灰背景、白色卡片、细边框、玫红强调。
- 统一按钮、表单、表格、弹窗、Toast、空状态等基础组件。
- 保持现有功能与数据不变；所有内容编辑流程不因样式改造而退化。

## 3. 非目标

- 不新增仪表盘、统计、搜索、筛选等新功能。
- 不修改数据模型、发布流程、构建流程或 REST API。
- 不重做页面编辑器的结构树、画布和属性面板内部交互。
- 不重写媒体库、用户等 Payload 默认视图，只做样式覆盖和入口裁剪。
- 不引入新的图标库或 UI 框架。

## 4. 已确认的设计决策

| 项目 | 决策 |
|---|---|
| 导航结构 | WordPress 式固定左侧栏 |
| 侧栏视觉 | 深石墨 `#242126`，玫红为强调色 |
| 侧栏行为 | 可折叠为 64px 图标栏，`localStorage` 记忆；移动端抽屉 |
| 内容页头 | 面包屑 → 标题/说明 → 右侧操作，取消页签 |
| 视觉方向 | 克制品牌感：暖灰、白卡、细边框、舒适密度 |
| 导航入口 | 内容：页面、媒体库、菜单、站点设置；系统：用户 |
| 后台首页 | 页面列表；品牌和面包屑「首页」均回到页面列表 |
| API | 全部管理界面入口移除，接口保留 |
| 版本 | 管理界面入口移除，版本数据保留 |
| 媒体库/用户 | 保留 Payload 默认结构，仅做视觉覆盖 |

## 5. 布局与样式规范

### 5.1 设计令牌

在后台样式中定义并统一引用：

```css
--adm-bg: #F7F5F6;
--adm-surface: #FFFFFF;
--adm-border: #EDE4E8;
--adm-text: #332B2F;
--adm-text-muted: #7C6B73;
--adm-text-soft: #A08B95;
--adm-primary: #C2185B;
--adm-primary-hover: #A1144B;
--adm-accent: #E60039;
--adm-success: #1B7A3A;
--adm-danger: #B42318;
--adm-warning: #9A5B00;
--adm-sidebar: #242126;
--adm-sidebar-hover: #312C31;
--adm-sidebar-active: #3B353A;
--adm-radius-card: 10px;
--adm-radius-control: 6px;
--adm-radius-modal: 12px;
--adm-control-height: 36px;
--adm-shadow-card: 0 1px 2px rgba(60, 30, 45, .04);
```

字体使用系统中文栈。正文 13px，页标题 24px，卡片标题 14px，说明/标签 12px，小号辅助文字 11px。间距按 8px 网格。

### 5.2 侧栏

- 桌面展开宽度 224px；折叠宽度 64px；固定在视口左侧，内容区相应留出边距。
- 顶部品牌区：Logo/标识 + “中惠文化” + 折叠按钮。点击品牌进入页面列表。
- 分组标题“内容 / 系统”，小号大写/弱化处理。
- 导航项：18px 线性图标 + 文字，行高 38px，圆角 6px。
- 当前项：`--adm-sidebar-active` 背景、白色文字、左侧 3px 玫红指示条，并设置 `aria-current="page"`。
- 悬停：`--adm-sidebar-hover`。
- 折叠态只显示图标，`title` 与 `aria-label` 提供名称；当前项保留指示条。
- 底部：查看网站、账号菜单（账号设置、退出登录）、折叠/展开按钮。
- 折叠状态写入 `localStorage`，键名 `zhonghui.admin.sidebar`，值为 `expanded` / `collapsed`。
- 移动端 <900px 时侧栏隐藏为抽屉，显示遮罩；`Esc`、遮罩点击、导航点击后关闭。

### 5.3 移动端工具条

<900px 时显示 52px 顶部工具条：菜单按钮、品牌、账号头像。工具条固定在顶部，内容区增加顶部内边距。

### 5.4 面包屑与页头

- 面包屑位于内容区顶部，格式：
  - 页面列表：`首页`
  - 菜单：`首页 / 菜单`
  - 站点设置：`首页 / 站点设置`
  - 页面编辑器：`首页 / 页面 / 编辑：<标题>`
- “首页”链接到 `/admin/collections/pages`；中间层级可点击。
- 页头为统一区块：
  - 面包屑 11–12px，弱化颜色；
  - 标题 24px，粗体；
  - 说明 12px，次要颜色；
  - 操作按钮在右侧，与标题底部对齐；
  - 底部 1px 分割线；
  - 页头不吸顶，滚动时随内容移动。
- 自定义页面不再渲染 Payload 文档头，也不再显示 `编辑 / API / 版本` 页签。

### 5.5 内容区

- 背景 `--adm-bg`。
- 主体最大宽度 1360px，水平内边距 32px；窄屏 20px。
- 页面列表、菜单表格可占满主体宽度；站点设置表单最大宽度约 960px，避免输入框过长。
- 卡片之间间距 12–16px；分组之间 20–24px。

## 6. 通用组件

### 6.1 按钮

- 主按钮：玫红实底、白字、6px 圆角、36px 高。
- 次按钮：白底、`--adm-border` 边框、正文色。
- 文字/危险按钮：无底色；危险操作使用 `--adm-danger`。
- 页头最多一个主按钮；危险操作不与主操作并排强调。
- 禁用态降低透明度并禁用指针；加载态显示“保存中…”等文字，不改变宽度。

### 6.2 卡片

- 白底、1px 边框、10px 圆角、20px 内边距、轻阴影。
- 卡片标题 14px，玫红或正文强调色；说明 12px 次要色。
- 设置页保持单列分组；宽屏下组内表单可两列，窄屏单列。

### 6.3 表单

- 标签在上，12px；输入框高 36px、6px 圆角、白底细边框。
- 聚焦时玫红描边 + 3px 低透明度外圈。
- 输入、下拉、上传按钮、二维码行保持同一垂直节奏。
- 上传按钮使用覆盖式透明文件输入，兼容 Safari 与自动化环境。
- 必填/错误提示显示在字段下方，使用危险色。

### 6.4 表格

- 白色卡片承托，表头浅灰底、12px 次要色。
- 行高约 48px，底部分割线；悬停行浅粉背景。
- 状态使用胶囊标签：已发布（绿）、草稿（灰/黄）。
- 操作列右对齐，使用文字按钮；删除使用危险色。
- 窄屏允许横向滚动，不压缩操作列。

### 6.5 弹窗与 Toast

- 弹窗：12px 圆角、24px 内边距、深色半透明遮罩；标题 18px，右上角关闭按钮。
- 打开时焦点进入首个输入框；`Esc` 关闭（保存中除外）。
- Toast：固定右上，距顶部 72px；成功/错误配色；3 秒自动消失。

### 6.6 状态与图标

- 空状态：简洁线性图标 + 一句说明 + 可选主操作。
- 加载状态：小号加载指示 + “加载中…”，不整页闪烁。
- 图标统一为内联 SVG，线性风格，默认 18px；不使用烘焙颜色的图片。

## 7. 页面改造

### 7.1 页面列表（后台首页）

- 页头：标题“页面”、说明、右侧“重建站点”（次按钮）与“新建页面”（主按钮）。
- 表格列：标题、路由、状态、更新时间、操作。
- 操作：编辑、配置、删除。
- 重建中按钮显示“构建中…”，完成后 Toast 提示。

### 7.2 菜单

- 保留嵌套表格、拖拽、↑↓、自动保存、弹窗编辑。
- 页头右侧显示保存状态与“添加菜单项”。
- 保存状态使用颜色区分：保存中（警告色）、已保存（成功色）、失败（危险色 + 重试）。
- 表格与弹窗应用统一组件样式。

### 7.3 站点设置

- 保留页头/页脚分组、Logo 上传、信息行增删排序、二维码增删、联系按钮、语言与版权。
- 页头操作：恢复默认（次按钮）、保存更改（主按钮）。
- 卡片统一间距与标题层级；页脚 Logo 预览保持深色底以显示白色 Logo。
- 保存成功后 Toast；静态站生效仍需“重建站点”。

### 7.4 页面编辑器

- 仅调整外壳顶栏：
  - 返回页面列表；
  - 面包屑/标题与发布状态；
  - 预览、保存、发布按钮；
  - 移除 API 与版本入口。
- 结构树、画布、属性面板的布局和交互保持不变，仅复用新的颜色、边框和控件样式。
- 继续使用现有 `html.ed-route` 隐藏 Payload 默认头部。

### 7.5 媒体库与用户

- 保留 Payload 默认列表、编辑表单、上传和权限功能。
- 通过后台样式覆盖将底色、卡片、按钮、表格、输入框对齐新视觉。
- 隐藏文档头中的 API 与版本入口。
- 不新增自定义列表逻辑。

### 7.6 登录与账号页

- 登录页沿用 Payload 结构，仅统一背景、卡片和主按钮颜色。
- 账号页保留默认功能；侧栏底部账号菜单提供“账号设置”和“退出登录”。

## 8. 技术设计

### 8.1 组件

- `AdminNav`：通过 `admin.components.Nav` 注册；读取 Payload 配置与当前用户，渲染侧栏、移动抽屉、账号菜单和折叠状态。
- `AdminBreadcrumb`：接收 items，渲染链接与当前项。
- `AdminPageHeader`：接收标题、说明、操作和面包屑，供自定义页面复用。
- `admin-icons`：内联 SVG 图标集合（页面、媒体、菜单、设置、用户、折叠、外部链接、退出等）。
- `admin-shell.css` / 后台样式入口：定义令牌、侧栏、通用组件和 Payload 覆盖规则。

选中态基于 `usePathname()` 判断，覆盖集合列表/编辑与 Globals 子路径。

### 8.2 隐藏与覆盖 Payload 默认结构

- 在后台 HTML 上增加管理外壳类（例如 `admin-shell`），由服务端首屏和客户端路由同步维护，登录/找回密码等未登录页不添加。
- `admin-shell` 下隐藏 `.app-header`；由自定义侧栏接管导航。
- 自定义页面通过类或选择器隐藏 Payload 文档头，改用 `AdminPageHeader`。
- 媒体库/用户保留文档头，仅隐藏其中 API 与版本链接。
- 移除编辑器 `TopBar` 中 API 与版本链接。
- 不删除版本集合、版本表或 REST 端点。

### 8.3 响应式

- `≥1280px`：按用户记忆展开或折叠；首次访问默认展开。
- `900–1279px`：保留用户选择；折叠侧栏悬停显示名称。
- `<900px`：抽屉 + 移动工具条，内容单列。
- 折叠状态只影响桌面；移动端始终以抽屉形式呈现。

### 8.4 状态与错误

- 导航链接使用真实路由，不依赖客户端状态注入。
- 折叠状态解析失败时回退为展开。
- 账号菜单点击外部或按 `Esc` 关闭。
- 保存/构建/上传沿用现有错误处理，并统一 Toast 样式。

## 9. 实施边界

- 不修改 `pageConfig`、页面文档结构、生成器输出结构或发布逻辑。
- 不新增依赖。
- 不删除数据库中的版本数据。
- 不改变现有 API 路由和权限。
- 不重写媒体库、用户页的默认交互。
- 所有颜色通过设计令牌引用，不在组件中散落硬编码。

## 10. 验收标准

### 视觉与布局

- 管理后台只保留一条全局左侧导航，不再出现顶部全局栏与文档页签叠加。
- 侧栏可展开/折叠，刷新后保持状态；移动端为抽屉。
- 自定义页面均有面包屑与统一页头。
- 页面列表、菜单、站点设置、页面编辑器顶栏视觉一致。
- 媒体库/用户页无明显旧样式残留。

### 功能回归

- 页面、媒体库、菜单、站点设置、用户入口均可访问。
- API 与版本入口不再出现在管理界面；对应接口仍可访问。
- 站点设置保存、上传、恢复默认正常。
- 菜单新增、删除、拖拽、自动保存正常。
- 页面列表新建、编辑信息、删除、重建站点正常。
- 页面编辑器预览、保存、发布正常。

### 响应式与可访问性

- 1280px、1024px、390px 三种宽度下无横向溢出或遮挡。
- 键盘可操作侧栏、抽屉、账号菜单与折叠按钮。
- 当前导航项有 `aria-current`，图标按钮有名称。
- 深色侧栏文字对比度达到 WCAG AA。

### 质量门禁

- `npx tsc --noEmit` 通过。
- 现有测试全部通过。
- Playwright 覆盖桌面/移动端主要路由与关键交互。
