# 富文本图片与图集编辑设计

日期：2026-10-31
状态：已确认，待实现
范围：富文本编辑器内单图的替换/移除、图集的整组替换与增删

## 1. 背景

富文本编辑器目前通过 `rich-image` 和 `image-row` 节点插入图片：

- 单图节点只提供「移除图片」，无法替换。
- 图集节点提供列数和「移除图集」，无法替换、增加或删除其中某张图片。
- 图片节点是 Lexical `DecoratorNode`，媒体选择与上传由 `MediaModal` 统一提供。

本次目标是把图片编辑补齐，同时复用现有插入图片/插入图集的交互和媒体能力，不引入新的数据模型。

## 2. 目标

- 富文本单图可以点击替换，并保留节点位置。
- 富文本图集可以点击打开原插入图集弹窗，自动选中当前图片，通过增删选择更新整组图片。
- 所有编辑即时进入 Lexical 历史，可撤销/重做。
- 保持现有插入流程、静态转换、保存/预览链路不变。

## 3. 非目标

- 不做图集内图片拖动排序。
- 不做手动 Alt 文本编辑，替换/添加时沿用媒体库的 `alt`。
- 不做媒体库内删除、批量跨图集操作。
- 不修改数据库字段或 Lexical 节点序列化版本。

## 4. 交互设计

### 4.1 单图

- 图片本身是可点击按钮，点击打开单选媒体弹窗。
- 弹窗打开时预选当前图片并高亮。
- 选择另一张图片后立即替换当前节点，节点位置不变。
- 图片下方保留「移除图片」。

### 4.2 图集

- 点击图集内任意图片，打开与插入图集相同的多选媒体弹窗。
- 打开时按当前图片顺序预选；用户可取消已有图片或选择新图片。
- 确认后整组图片按当前选中顺序更新：
  - 取消的图片被删除。
  - 新选图片追加到末尾。
  - 图集列数和其他图片位置保持不变。
- 图集工具条保留「列数」和「移除图集」。
- 未选任何图片时确认按钮禁用；清空整组请使用「移除图集」。
- 第一版不支持在弹窗内排序，新增图片按点击顺序追加。

### 4.3 通用

- 图片点击区域使用 `<button type="button">` 包裹，支持键盘访问。
- 节点内按钮阻止事件冒泡，避免触发布局选择或关闭富文本弹窗。
- 嵌套媒体弹窗只关闭自身，不关闭外层富文本编辑器。
- 取消弹窗不产生任何数据修改。

## 5. 组件与数据流

### 5.1 `MediaModal`

新增可选属性：

```ts
initialImages?: Array<{ src: string; alt?: string }>
confirmVerb?: string // 默认「插入」
```

行为：

- 多选模式下，根据 `initialImages` 初始化选中集合。
- 匹配媒体库时按 URL 关联真实媒体项；匹配不到时保留该 URL 的临时项，避免误删旧图。
- 多选确认按钮文案为 `${confirmVerb} ${selected.length} 张`；编辑图集时传「更新」，插入时保持「插入」。
- 单选模式同样显示当前图片选中态；选择新图片仍走现有 `onSelect`。
- 插入图片/图集不传 `initialImages`，行为完全不变。

### 5.2 `ImageNode`

新增方法：

```ts
setImage(src: string, alt?: string): void
```

- 在 `ImageView` 中通过 `editor.update` 调用。
- 只修改 `__src` / `__alt`，不改变节点在文档中的位置。
- 点击图片打开单选 `MediaModal`；选中后调用 `setImage` 并关闭弹窗。

### 5.3 `ImageRowNode`

新增方法：

```ts
setImages(images: ImageRowItem[]): void
```

- 在 `ImageRowView` 中通过 `editor.update` 调用。
- 图集点击任意图片打开多选 `MediaModal`，传入当前 `images`。
- 确认后把选中项映射为 `{ src, alt }` 并整组写回；列数保持不变。

### 5.4 渲染与同步

- 节点变更触发 Lexical `OnChangePlugin`，沿用现有保存、Canvas 实时渲染和独立预览同步。
- `RichTextView` 的 React 渲染路径会按新节点数据更新图片，不需要改静态转换器。
- 现有 `lexicalToHtml` 继续处理 `rich-image` / `image-row`，输出结构不变。

## 6. 视觉与可访问性

- 图片按钮保持原图片比例、圆角和网格布局。
- 增加 `cursor: pointer` 和清晰的键盘 focus 轮廓。
- 不新增常驻遮挡图片的按钮层；编辑入口就是图片本身。
- 「移除图片」「移除图集」保持现有文字按钮样式。

## 7. 边界处理

- 当前图片不在媒体库列表：仍保留在选中集合，允许继续编辑，不静默丢弃。
- 选择同 URL 图片：视为同一项，不产生重复。
- 图集选择为空：禁用确认；不通过弹窗清空图集。
- 上传新图片：沿用 `MediaModal` 现有上传逻辑；上传成功后按当前模式预选或直接替换。
- 节点被删除后弹窗关闭：不执行残留回调。

## 8. 测试

- `MediaModal`
  - 多选 `initialImages` 预选顺序正确。
  - `confirmVerb` 文案正确。
  - 取消不触发回调；确认返回当前选中顺序。
  - 未匹配媒体库的旧图仍保留。
- `ImageNode`
  - `setImage` 更新 `src/alt` 并正确 `exportJSON`。
- `ImageRowNode`
  - `setImages` 增删/替换后图片顺序与列数正确。
- 交互
  - 点击单图/图集打开对应弹窗并预选。
  - 取消不修改；确认后节点数据与 Canvas 即时更新。
- 回归
  - 现有插入图片、插入图集、上传、静态转换和保存流程测试继续通过。

## 9. 兼容与影响

- 不改 Payload 字段、数据库结构或节点版本号。
- 旧富文本内容无需迁移。
- 静态站点输出不变。
- 主要改动文件：`cms/src/editor/MediaModal.tsx`、`ImageNode.tsx`、`ImageRowNode.tsx`、`editor.css`、相关测试与 `docs/content-components.md`。
