# 文章管理后台改版（短设计）

**日期：** 2026-11-04
**范围：** 只调整 CMS 管理后台的信息架构、中文文案和文章表单布局；不改变前台 URL、数据模型和现有文章内容。

## 目标

- 把原来并列的「案例分类 / 案例 / 案例设置」收进一个「文章管理」父菜单。
- 底层继续使用现有 `case-categories`、`cases` 集合，只改后台显示名，避免影响 `/blog/...` 路由和已有数据。
- 表单改为中文、WordPress 风格：标题/固定链接/正文为主区域，分类/封面/日期在右侧栏。
- 菜单编辑器里的「案例分类」改为「文章分类」；移除文章汇总入口。

## 非目标

- 不重命名数据库集合 slug。
- 不改变 `/blog/`、`/blog/{分类}/`、`/blog/{分类}/{文章}/`。
- 不改变文章字段、迁移脚本或前台模板。
- 不新增作者、标签、评论、草稿预览等 WordPress 功能。

## 信息架构

侧边栏「文章管理」为可折叠父菜单：

```text
文章管理
├── 文章列表    /admin/collections/cases
└── 分类管理    /admin/collections/case-categories
```

- 进入任一子页面时父菜单自动展开。
- 其他分组（内容、系统）保持现状。
- 重定向集合 `case-redirects` 不进入侧边栏。

## 文案

| 当前 | 改为 |
|---|---|
| 案例 | 文章 |
| 案例分类 | 文章分类 |
| 案例设置 | 文章设置 |
| Slug | URL 别名 |
| SEO 标题 | 搜索标题 |
| SEO 描述 | 搜索描述 |
| 所属分类 | 文章分类 |
| 封面大图 | 封面图 |
| 汇总页每页条数 | 每页文章数 |
| 分类下每页条数 | 每页文章数 |
| 案例分类（菜单编辑器） | 文章分类 |

## 文章表单布局

主区域：

1. 标题
2. URL 别名（固定链接说明）
3. 正文

不显示搜索优化区域。现有 SEO 字段保留在数据库但后台隐藏，前台继续回退使用文章标题。

右侧栏：

- 文章分类
- 封面图
- 发布日期

发布状态与保存/发布按钮沿用 Payload 现有顶部操作区。

## 分类表单

- 分类名称、URL 别名、分类页 Banner、副标题、每页文章数。
- 分类的搜索字段同样在后台隐藏。
- 保留删除保护：分类下仍有文章时禁止删除。

## 验收

- 侧边栏出现可折叠「文章管理」，三个子页面可达，当前页高亮。
- 文章/分类/设置页面不再出现 `Slug`、`SEO` 等英文标签，也不显示搜索优化区域。
- 创建文章时可在右侧栏选择分类、封面和日期。
- 前台 `/blog/`、分类页、详情页保持不变。
- `tsc`、全量测试、`build:generator` 通过。
