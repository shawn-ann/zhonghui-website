### 3.1 区块背景交替规则（定版）

**Banner 之下的每个区块背景交替出现，直到页脚：**

| 序号 | 背景 |
|---|---|
| 第 1 块 | **背景图** `img/yinji-bg.jpg`（标题白字 `.title-on-image`，内容用白卡/白面板承托） |
| 第 2 块 | **浅粉底** `--light-blue` `#FFF1F6`（`.section-alt`） |
| 第 3 块 | 背景图 |
| 第 4 块 | 浅粉底 |
| … | 依此奇偶交替 |

- 无论区块数量多少，都按"图 / 粉 / 图 / 粉……"交替。
- **页脚不受此规则**（固定玫红渐变）。
- 背景图区块：标题必须白字，内容（文字/列表）需用白卡或半透明白面板承托以保证可读性。

> 现状核对（2026-10-09）：`index`（图/粉/图/粉）、`about`（图/粉/图/粉）、`cases`（图）、`aupair-usa`（图/粉/图）均符合。

## 4. 组件颜色

- **菜单**：白底；文字 `#E60039`（选中同色 + `#E60039` 下划线）；**无 hover 变色**。下拉菜单链接 `#E60039`，hover 底色 `#E60039`。
- **Logo**：`img/pink_logo_with_text_1.jpg`，白色页头上直接显示（无底板），高度占满菜单栏（88px）。
- **文字链接**（"查看详情 →" / "阅读全文"）：`#C2185B`。
- **图标**：内联 SVG，`stroke="currentColor"`，颜色由 `.adv-card .icon { color: var(--accent) }` 控制；圆环 `border-color: currentColor`——**图标描边与圆环同色，跟随 `--accent`**。
- **故事标签** `.tag`：底色 `--orange` `#E60039`，白字。

## 7. 布局 / 栅格（定版标准）

**基准宽度：`1200px`。** 全站各页的页头、区块、页脚都必须以 1200px 为内容宽度，左右边距才会一致。

| 区域 | 规则 |
|---|---|
| `.container` | `max-width: 1200px; margin: 0 auto; padding: 0 24px;` |
| `.footer-grid` | `max-width: 1200px; ...` |
| 响应式 | 视口 ≤ 1200+48 时容器随视口收缩，左右各保留 `24px` 内边距 |

- **页面（列表/内容页）**：`.container` 与 `.footer-grid` 一律 **1200px**。
- **文章详情页**（case-detail / news-detail）：外层 `.container` 用 **1200px**，使**菜单/页脚与全站对齐**；正文再用一个**内层窄容器**（约 **820px**）约束阅读宽度。
- **禁止**同一页面内 `.container` 与 `.footer-grid` 宽度不一致（会造成上下内容左右边距对不齐）。

> 历史遗留：早期各页用了 1000 / 1180 / 1280 / 900 等不同宽度，需统一到 1200。截至 2026-10-08，`index` / `about` / `cases` 已符合；`news` / `contact` / `project-swt` / `case-detail` / `news-detail` 待同步。

## 8. 切换主题的机制

- 颜色集中在 `:root`。要换主题，优先改 `:root` 变量。
- **图标/强调**统一走 `--accent`：改这一个变量，图标描边、圆环、标签等一并变色。
- Banner 支持预制布局变体（`options.layout`: `split` / `centered`），见 `docs/superpowers/specs/2026-10-01-banner-layout-variants-design.md`。
- 中惠优势图标为**内联 SVG**（`advIcons` 映射 + `stroke="currentColor"`），不再使用烘焙颜色的图片文件。
