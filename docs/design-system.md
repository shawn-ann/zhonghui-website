# 中惠文化门户网站 — 设计系统（配色 / 设计令牌）

> 主题：**玫红主调（Scheme A）**
> 更新日期：2026-10-08
> 适用范围：首页 `index.html`（当前唯一已套用该主题的页面）

本文件是**配色与设计令牌的唯一权威来源**。所有颜色集中在 `index.html` 的 `:root` CSS 变量中，组件通过 `var(--x)` 引用，**不要在组件里写死颜色**。

## 4. 组件颜色

- **菜单**：白底；文字 `#E60039`（选中同色 + `#E60039` 下划线）；**无 hover 变色**。下拉菜单链接 `#E60039`，hover 底色 `#E60039`。
- **Logo**：`img/pink_logo_with_text_1.jpg`，白色页头上直接显示（无底板），高度占满菜单栏（88px）。
- **文字链接**（"查看详情 →" / "阅读全文"）：`#C2185B`。
- **图标**：内联 SVG，`stroke="currentColor"`，颜色由 `.adv-card .icon { color: var(--accent) }` 控制；圆环 `border-color: currentColor`——**图标描边与圆环同色，跟随 `--accent`**。
- **故事标签** `.tag`：底色 `--orange` `#E60039`，白字。

## 6. 字体与排版（首页）

- 字体族：`-apple-system, "PingFang SC", "Microsoft YaHei", "Source Han Sans SC", sans-serif`
- 菜单：16px / 600
- Banner 大标题：48px / 700；副标题：24px / 500
- 区块标题 `.section-title h2`：32px / 700
- 卡片标题：19–20px / 600；卡片正文：14px

## 7. 切换主题的机制

- 颜色集中在 `:root`。要换主题，优先改 `:root` 变量。
- **图标/强调**统一走 `--accent`：改这一个变量，图标描边、圆环、标签等一并变色。
- Banner 支持预制布局变体（`options.layout`: `split` / `centered`），见 `docs/superpowers/specs/2026-10-01-banner-layout-variants-design.md`。
- 中惠优势图标为**内联 SVG**（`advIcons` 映射 + `stroke="currentColor"`），不再使用烘焙颜色的图片文件。
