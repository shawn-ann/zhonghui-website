# 初始化数据

这里保存当前站点的可导入配置，用于新环境一键初始化。

```
seed/
├─ manifest.json   # 页面、文章、分类、菜单、站点设置、媒体索引
└─ media/          # 媒体库原文件
```

## 导出当前配置

在 `cms/` 目录执行：

```bash
npm run seed:export
```

会重新生成 `seed/manifest.json` 并复制当前媒体文件到 `seed/media/`。

## 初始化新环境

确保数据库是空库，并已配置 `.env`：

```bash
npm run seed:init
```

脚本会按顺序：

1. 导入媒体文件并建立文件名映射；
2. 导入文章分类、文章；
3. 导入页面并重写区块中的媒体/页面/文章引用；
4. 恢复菜单和站点设置；
5. 自动执行 `npm run generate`，生成静态站并切换 `releases/current`。

初始化完成后，直接访问静态站即可；后台管理员账号不包含在种子中，需要首次访问 `/admin` 时创建。

可选参数：

```bash
npm run seed:init -- --skip-build   # 只导入数据，不生成静态站
```

说明：

- 脚本是幂等的：按文件名、分类 slug、文章 slug、页面 route 复用已有记录；
- 不会删除种子之外已有内容，生产初始化建议使用空库；
- 不包含 `releases/` 等静态产物，静态站由初始化最后一步重新生成。
